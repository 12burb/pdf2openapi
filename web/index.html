pdf2openapi runs in your browser, nothing uploaded

Drop a vendor's PDF API documentation. Get an OpenAPI 3.0 spec you can import into Postman, Insomnia or Bruno, or feed to a code generator. The PDF is read by your browser and never sent anywhere; close the tab and it is gone.
